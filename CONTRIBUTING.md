# Contributing to Szmelc-INC projects

Each repository may have its own `CONTRIBUTING.md`, issue templates, and review rules. Read those first. If a repository has no project-specific guide:

1. Search its issues and Discussions before starting a large change.
2. Open an issue for a substantial proposal; small, clear fixes can go directly to a pull request.
3. Use a focused branch and pull request. Explain the problem, the change, and how you checked it.
4. Respect the repository's `CODE_OF_CONDUCT.md` and security policy.
5. Wait for review and required checks. Do not merge your own outside contribution unless the repository explicitly grants you that authority.

By submitting a contribution, you agree that it may be distributed under the license already used by that repository. No organization-wide CLA is required. A project may state additional terms in its own contribution guide.
