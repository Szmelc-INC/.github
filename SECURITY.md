# Security policy

Security support and response times vary by repository. Check that repository's `SECURITY.md` for supported versions and project-specific contact details.

## Reporting a vulnerability

- Use the repository's private vulnerability reporting feature from its GitHub **Security** tab when available.
- Otherwise, contact that repository's maintainers through a documented private route.
- Do not report vulnerabilities in public issues, Discussions, or chat.

If no private route is documented, open a minimal issue asking for a private security contact. Do not include vulnerability details in that request. Once a private channel is established, include the affected repository, supported version or commit, impact, and steps to reproduce. Give maintainers a reasonable opportunity to investigate and prepare a fix before public disclosure.
