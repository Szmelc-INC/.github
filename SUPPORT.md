# Support

For help with an organization project:

1. Read the repository README and its `SUPPORT.md`, if present.
2. Ask usage questions in that repository's Discussions when enabled.
3. Open an issue for a reproducible bug or a concrete feature request, using its issue templates.
4. Report security vulnerabilities through the private process in `SECURITY.md`.

Include the repository, version or commit, relevant environment, and a short reproduction. Do not include credentials, personal data, or other secrets. Maintainers aim to acknowledge new issues and pull requests within 48 hours; this is a target, not a guarantee, and response time depends on volunteer availability.
